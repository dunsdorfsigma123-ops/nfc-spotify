Dein NFC-Tag merkt sich jeden Song automatisch

Tag scannen, aktueller Spotify-Song landet automatisch in "Songs, die dir gefallen" – ganz ohne App. Die Einrichtung dauert etwa 15 Minuten und ist kostenlos. Du brauchst dafür keine Programmierkenntnisse, nur Copy & Paste.

1Eigene Spotify-App anlegen

Jeder Tag braucht eine eigene, kostenlose Spotify-Entwickler-App – das ist eine reine Formalität und dauert 2 Minuten.

  1. Geh auf developer.spotify.com/dashboard und logg dich mit deinem Spotify-Konto ein.
  2. Klick auf "Create app".
  3. Name und Beschreibung sind frei wählbar, z. B. "Mein NFC Song-Tag".
  4. Bei Redirect URI trägst du erstmal irgendetwas ein, z. B. https://example.com – das korrigierst du in Schritt 4, sobald du deine echte Adresse kennst.
  5. Bei "Which API/SDKs are you planning to use?" nur Web API ankreuzen.
  6. Speichern. Auf der folgenden Seite siehst du deine Client ID – die brauchst du gleich in Schritt 3.
Spotify erlaubt aktuell maximal 5 Personen pro App (im sogenannten "Development Mode"). Da hier aber jeder seine eigene App anlegt, betrifft dich das nicht – deine App bedient nur dich selbst.

2GitHub-Repository erstellen

Die Seite muss irgendwo im Internet erreichbar sein. GitHub Pages hostet sie kostenlos.

  1. Konto auf github.com erstellen (falls noch nicht vorhanden).
  2. Oben rechts auf "+" → "New repository".
  3. Einen Namen vergeben, z. B. mein-song-tag. Sichtbarkeit auf Public lassen.
  4. Auf "Create repository" klicken.

3Vorlage herunterladen und Client ID eintragen

Lad dir die fertige Vorlagen-Datei herunter und trag dort deine eigene Client ID aus Schritt 1 ein.

index.html (Vorlage)
Code unten kopieren – funktioniert auf jedem Handy

Falls der Button nicht reagiert: In das Feld tippen, gedrückt halten, "Alles auswählen" → "Kopieren" wählen.

  1. Die heruntergeladene Datei mit einem einfachen Texteditor öffnen.
  2. Die Zeile mit DEINE_SPOTIFY_CLIENT_ID suchen und durch deine eigene Client ID aus Schritt 1 ersetzen.
  3. Datei als index.html speichern (Name muss exakt so lauten).
  4. Im GitHub-Repository auf "Add file" → "Upload files" klicken, die Datei hochladen, mit "Commit changes" bestätigen.
Der Dateiname muss exakt index.html lauten (nicht index_1.html o. ä.), sonst findet GitHub Pages die Seite nicht automatisch.

4GitHub Pages aktivieren

  1. Im Repository oben auf "Settings" klicken, dann links auf "Pages".
  2. Bei "Branch" main auswählen, Ordner auf / (root) lassen, "Save" klicken.
  3. Nach 1–2 Minuten erscheint oben eine grüne Meldung mit deiner fertigen Adresse, z. B. https://deinname.github.io/mein-song-tag/.

Diese Adresse jetzt kopieren und im Spotify-Dashboard aus Schritt 1 unter "Redirect URIs" eintragen (die Platzhalter-Adresse von vorhin ersetzen). Speichern.

Die Adresse muss in Spotify und in der Browserleiste zu 100 % identisch sein, inklusive Schrägstrich am Ende.

5NFC-Tag beschreiben

  1. App "NFC Tools" installieren (App Store / Play Store).
  2. Im Reiter "Write" → "Add a record" → "URL / URI" auswählen.
  3. Deine Adresse aus Schritt 4 einfügen.
  4. Auf "Write" tippen und das Handy an den NFC-Tag halten, bis die Bestätigung kommt.

6Einmalig verbinden

Tag mit dem Handy scannen (am besten im normalen Browser, nicht über WhatsApp/Instagram-Vorschau). Auf "Mit Spotify verbinden" tippen und den Zugriff bestätigen. Das ist der einzige Klick, den es je braucht – jeder weitere Scan läuft komplett automatisch.

?Problemlösung

"Etwas ist schiefgelaufen" mit Status 403 beim Speichern

Das war ein alter, inzwischen von Spotify abgeschalteter Endpunkt. In der aktuellen Vorlagen-Datei ist das bereits korrigiert – lad dir bei Problemen einfach die neueste Version über den Button oben erneut herunter.

Die Seite zeigt 404 / "Seite nicht gefunden"

Meist ist GitHub Pages noch nicht fertig aktiviert oder braucht noch 1–2 Minuten. Prüfe außerdem, dass die Datei wirklich index.html heißt und direkt im Hauptverzeichnis liegt.

Fehler beim Verbinden, obwohl alles richtig eingetragen ist

Öffne die Adresse direkt in Safari/Chrome, nicht über die Vorschau einer anderen App (WhatsApp, Instagram etc.) – diese eingebauten Browser blockieren manchmal den nötigen Zwischenspeicher.

"Gerade läuft kein Song", obwohl Musik läuft

Prüfe in der Spotify-App unter Einstellungen, ob "Private Sitzung" aktiviert ist – das versteckt absichtlich, was gerade läuft. Außerdem muss der Song auf demselben Konto laufen, mit dem die Seite verbunden ist.

Ich will die Verbindung zurücksetzen oder ein anderes Konto benutzen

Rufe deine Adresse mit angehängtem ?reset=1 auf, z. B. https://deinname.github.io/mein-song-tag/?reset=1. Das löscht die gespeicherte Verbindung und zeigt wieder den "Verbinden"-Button.

Diese Anleitung gehört zum 3D-Druck-Projekt "NFC Song-Tag". Jede Einrichtung läuft über dein eigenes, kostenloses Spotify- und GitHub-Konto.
